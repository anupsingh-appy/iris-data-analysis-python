# Iris Flower Data Analysis using Python

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Iris dataset using Python libraries such as Pandas, Matplotlib, and Seaborn.

The goal of this project is to analyze flower measurement data, identify patterns, visualize relationships, and generate analytical insights.

---

## Tools & Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

---

## Dataset Information
The dataset contains 150 flower observations with the following features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

The species included are:
- Setosa
- Versicolor
- Virginica

---

## Steps Performed
1. Data Loading using Pandas
2. Dataset Inspection
3. Statistical Summary
4. Duplicate Value Check
5. Exploratory Data Analysis (EDA)
6. Data Visualization
7. Correlation Analysis
8. Insight Generation

---

## Visualizations Created
- Count Plot
- Histogram
- Box Plot
- Scatter Plot
- Pair Plot
- Correlation Heatmap

---

## Key Insights
- The dataset contains no missing values.
- Petal length and petal width show strong positive correlation.
- Setosa species is clearly distinguishable from the other species.
- Virginica flowers generally have larger measurements.
